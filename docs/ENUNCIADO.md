# Assignment summary

The original screenshots are preserved in this repository under `enunciado/`.

The assignment asks for a decentralized precision-agriculture system using SPADE.
Drones, soil sensors, irrigation units, fertilizer/logistics units and harvesters must
collaborate without a central farm controller. They monitor crop conditions, allocate
limited water, fertilizer and fuel, react to drought, pests and equipment failures,
and coordinate tasks through the Contract Net Protocol.

Required evaluation areas include crop yield, water and fertilizer efficiency,
harvesting time, responsiveness to environmental changes and collaboration quality.
